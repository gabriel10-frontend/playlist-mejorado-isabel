# Playlist – versión corregida

## Cómo abrirla

Abre `index.html` en Chrome, Brave, Edge o Firefox. Mantén todos los archivos juntos en la misma carpeta. Para publicarla en GitHub Pages, sube todos los archivos de esta carpeta.

## Qué se conserva

- Diseño del reproductor, carrusel y cinco canciones originales.
- Archivos MP3 originales sin modificar.
- Texto de bienvenida y títulos de las canciones.

## Qué se corrigió

- Al pulsar una portada se actualizan a la vez canción, reproductor y fondo.
- Carrusel sin tarjetas superpuestas de las canciones lejanas.
- Reproducir, pausar, anterior, siguiente y cambio automático al terminar cada canción.
- Barra de progreso interactiva para adelantar o retroceder.
- Duración y tiempos tomados de cada MP3 real.
- Favoritos individuales, guardados localmente en el navegador cuando el almacenamiento está disponible.
- Portadas de respaldo locales si los enlaces originales dejan de cargar.
- Ajustes para celulares y navegación por teclado.

## Diseño nuevo

Solo se rediseñó la bienvenida: ahora tiene fondo de acuarela de Machu Picchu (`fondo_acuarela.webp`), animaciones suaves y un disco decorativo. El fondo aparece también detrás del reproductor, de forma tenue, sin cambiar la distribución original.

## Nota

Los enlaces originales de las portadas siguen siendo externos. Los archivos `portada-respaldo-1.svg` a `portada-respaldo-5.svg` aparecen automáticamente si esas imágenes no se pueden cargar.
